# Immersive_Aircraft_Modernization / 沉浸飞机：现代化

## English
Immersive_Aircraft_Modernization adds the Overclocked Cruise Guidance Module for Immersive Aircraft.

Features
- Route editing with named waypoints
- Default and per-waypoint flight altitude
- HUD fuel display with item and liquid fuel support
- Auto navigation with pause/resume
- Overclock cruise acceleration
- Holding pattern, fastest landing, and vertical landing modes

Controls
- `,` opens route settings
- `.` toggles auto navigation

Required dependency: Immersive Aircraft.
Built for Minecraft 1.20.1 Forge.

## 中文
沉浸飞机：现代化为沉浸飞机增加“超频巡导模块”。

功能
- 航线编辑，支持航点命名
- 默认飞行高度与单航点飞行高度
- 信息 HUD 显示燃料，兼容物品燃料与液体燃料
- 自动导航，支持暂停/继续
- 超频巡航加速
- 盘旋、最快降落、垂直降落三种终点模式

快捷键
- `,` 打开航线设置
- `.` 启动或切换自动导航

必需前置：沉浸飞机。
适用于 Minecraft 1.20.1 Forge。
